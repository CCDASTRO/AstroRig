PixInsight · Master preparation

CCDASTRO Master Workflow v0.4.1

Choose existing calibration, registration, integration, OSC dual-band extraction and channel-combination tools from one session planner. Version 0.4.1 adds build-1718 registration-project guidance and review-only quintic interpolation. Batch preprocessing includes WBPP, FBPP and separately installed GPUStacker. Prepare HDRComposition from short, medium and long masters, with header-based exposure detection and a configured interface for review before you execute. Supports mono LRGB/Ha/OIII/SII, OSC and OSC plus narrowband data. Signed development release with PI 1.9.5–1.9.6 updater compatibility; install through PixInsight Update Manager.
