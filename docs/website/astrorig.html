AstroRig

Keep one astrophotography equipment inventory, build multiple imaging rigs, and see how much they weigh, cost, and contribute to backfocus.

Install or update

  1. Close AstroRig if it is running, then run the Windows installer. The default installation is for the current user.
  2. Open AstroRig from the Start menu. Setup also offers a desktop shortcut.
  3. When upgrading, reuse the existing install directory. If you previously used a portable copy, use Open in the installed app to choose your inventory if it does not reopen automatically.

Find and back up your files

Paste any of these paths into File Explorer’s address bar. The app’s bottom status bar shows the full path to the inventory you’re currently using.

Installed application
%LOCALAPPDATA%\Programs\AstroRig\AstroRig.exe
Default inventory
%LOCALAPPDATA%\ImagingRig\inventory.json. AstroRig creates it on the first save to that path.
Inventory saved elsewhere
Open selects an existing JSON file. Save As creates a separate file and makes it the active inventory. Save writes to the active file.
Last opened inventory
%LOCALAPPDATA%\ImagingRig\last-inventory.txt stores the path to reopen. The N.I.N.A. plugin keeps its own path in nina-last-inventory.txt in the same folder.
Excel workbook
Export Excel saves an .xlsx wherever you choose.

Save your edits and copy the active JSON file to back up your inventory. If that file lives inside an old portable app folder, move a copy to a safe location before removing the old folder.

Add equipment and build a rig

  1. Open Equipment → Add equipment, choose a type, and enter the model and specs. You can use an optional preset and fill in the details for your hardware. Enter weights in kilograms.
  2. Open Rigs → Add rig and use Assign equipment to add items. Set each component’s role, payload and backfocus checkboxes, and order. Enter sensor binning and save.
  3. Read the rig summary or hover over an equipment name for its saved specs. Select Show rig cost to total the recorded purchase prices of assigned equipment and loaded filters, counting each item once.

Read the rig summary

  • Image scale and field of view use the saved camera and optical specs. The first item assigned to each primary role supplies the specs.
  • Payload and headroom show kilograms and pounds. Payload sums checked components, excluding the mount and tripod by default. Headroom uses the mount’s imaging target when supplied, or its rated capacity.
  • Backfocus uses a positive rig override first, then the reducer’s requirement, then the telescope’s requirement. Use the camera’s sensor-to-mounting-surface distance and the spacing of other checked components. Zero remaining matches the target. A negative value means the recorded train is too long.

Assign filter-wheel slots

Add each filter separately as Filter, then add a Filter Wheel and set the number of slots. Select the wheel and click Assign filters to slots. Choose a filter or (Empty) for each slot and save. Hover over the wheel name in standalone AstroRig to see occupied slots. N.I.N.A. lists them directly in its rig table.

Import and export

Import AstroArmory backup reads equipment, supported specs, and rig assignments from a SQLite .db file. Check the imported specs against your hardware. Reimporting the same file adds duplicate records.

Export Excel creates a filterable workbook with Equipment, Rigs, and Rig Components. It opens directly on Equipment.

Choose how to display equipment

In AstroRig for Windows, open Equipment and choose Alphabetical for one A–Z list or By type for collapsible groups such as Focuser, Mount, and Filter.

Use AstroRig in N.I.N.A.

In the AstroRig imaging panel, choose Rig order, Alphabetical, or By type beside the rig selector.

To install or update from the catalog when your version is listed, open Plugins in N.I.N.A. The manual download is also available below.

  1. Download the AstroRig 1.0.6 plugin ZIP. It targets the N.I.N.A. 3.3.0.1069 nightly plugin API.
  2. Close N.I.N.A., then extract the ZIP contents into %LOCALAPPDATA%\NINA\Plugins\3.0.0\AstroRig. Restart N.I.N.A., check Plugins → Installed, and open AstroRig from the Imaging panel selector.
  3. Use Open inventory and choose the same JSON file as standalone AstroRig. After saving changes in standalone, click Reload in N.I.N.A. After editing in N.I.N.A., reopen the JSON in standalone before saving there.
